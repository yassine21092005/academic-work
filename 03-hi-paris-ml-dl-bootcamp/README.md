# Hi! PARIS Data Boot Camp 2026: Machine Learning and Deep Learning final project

Project from the 5-day Hi! PARIS Data Boot Camp (Institut Polytechnique de Paris and HEC Paris), September 2026.

- `ml_dl_final_project.ipynb`: end-to-end notebook on the "Impact of AI on Students" dataset (Kaggle, synthetic data; the dataset itself is not included).

**Content**
- Feature engineering and train/test splits, one-hot and ordinal encoding, scaling.
- Classification (burnout level prediction): logistic regression, random forest, XGBoost.
- Regression (academic outcome): XGBoost regressors.
- Model explainability with SHAP.
- Deep learning: Keras `Sequential` neural networks.

**Skills:** Python, pandas, scikit-learn, XGBoost, SHAP, TensorFlow/Keras.
