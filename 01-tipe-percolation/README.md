# TIPE (preparatory classes): Percolation and phase transition

Research project presented at the competitive entrance exams to French engineering schools (June 2025).

- `tipe_slides.pdf`: oral presentation (in French).
- `mcot.pdf`: MCOT summary (thematic positioning, keywords, commented bibliography).

**Content**
- Bond percolation on the lattice Z²: open edges with probability p, open clusters, percolation probability θ(p).
- Phase transition at a critical value p_c, using Kolmogorov's 0-1 law.
- Planar duality (dual graph) and tools on increasing events.
- Algorithm: Union-Find with path compression, used to estimate percolation thresholds by numerical simulation.
- Extension: invasion percolation with gravity (random thresholds, modified threshold p + g·y).

**Skills:** probability, graph theory, algorithms, numerical simulation.
